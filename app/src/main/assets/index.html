对话模式

· 纯预设：关键词触发回答，没命中就随机。不联网、不花钱。
· AI 对话：把你的话发给云端大语言模型生成回答。
· 两者互斥。Base URL / API Key / 模型 没填全时，会强制用纯预设。

对话

主动回复

每 45 秒检查一次，概率越低越安静。
戳一戳、睡着、醒来、主动开口，都按这个概率决定走 AI 还是用预设。没配好接口时一律用预设。1 = 全部走 AI，0 = 全部用预设。

对话历史与记忆

这两个是分开的：
· 记忆 = 每次发给模型的最近对话，决定 Sans 还记不记得聊过什么
· 对话历史 = 你在历史窗口里能翻到的记录
配置会在重启桌宠后生效。

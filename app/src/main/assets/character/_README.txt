SansPet 角色素材目录

所有角色图都放这里。文件名是程序认的，放进去就自动生效，不用改代码。
缺哪个就用兜底方案，不会报错。

---------------- 命名规则（重要）----------------

  单张：        名字.png            例：blink.png
  多帧动画：    名字_0.png
                名字_1.png
                名字_2.png  …      从 0 开始连续编号，缺一张就停

  多帧的播放速度是每 0.5 秒一张，循环播。

--------------------------------------------------

1) 待机主图
     idle.png

2) 睡觉（多帧，循环播）
     sleep_0.png
     sleep_1.png

3) 待机表情（多帧或单张都行）
     wink_0.png    wink_1.png      眨眼（两帧）
     blink.png                     合眼（单张）
     look.png                      眼瞟别处（单张）

4) 走动序列帧（4 个方向，各自编号）
     walk/down_0.png   walk/down_1.png  …
     walk/left_0.png   walk/left_1.png  …
     walk/right_0.png  walk/right_1.png …
     walk/up_0.png     walk/up_1.png    …

     注意：走动的换帧速度是 0.15 秒一张（比其他状态快），
     这样走起来才自然。想改，改 overlay.js 里的帧间隔。

---------------- 尺寸建议 ----------------

  - 透明背景 PNG
  - 各图尺寸要一致，否则切换状态时会跳位
  - 建议高宽比接近 1 : 1（正方形），布局槽位就是按这个设计的
  - 图片本身留白不要太多，程序不会自动裁

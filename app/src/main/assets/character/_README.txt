SansPet 角色素材目录

所有角色图都放这里。下面这些文件名是程序认的，放进去就自动生效，
不用改任何代码。缺哪个就用兜底方案，不会报错。

--------------------------------------------------
1) 待机（主图，必放）
--------------------------------------------------
  idle.png

  就是平时站着的 Sans。
  想换角色图，替换这个文件即可。

  没有这个文件时，程序会退回用上一层的 sans.png。

--------------------------------------------------
2) 睡觉
--------------------------------------------------
  sleep.png          可选

  睡觉时显示。没有的话，程序会把 idle.png 放倒一点 + 半透明来区分。

--------------------------------------------------
3) 走动序列帧（4 个方向 × 4 帧）
--------------------------------------------------
  walk/down_0.png    walk/down_1.png    walk/down_2.png    walk/down_3.png
  walk/left_0.png    walk/left_1.png    walk/left_2.png    walk/left_3.png
  walk/right_0.png   walk/right_1.png   walk/right_2.png   walk/right_3.png
  walk/up_0.png      walk/up_1.png      walk/up_2.png      walk/up_3.png

  每 150 毫秒换一帧，0 -> 1 -> 2 -> 3 -> 0 循环。
  只放其中几张也能用：程序只认 walk/down_0.png 是否存在，
  存在就认为这个方向有素材（所以同一个方向的 4 帧要一起放）。
  一个方向都没有的话，走动时用 idle.png 静态显示。

--------------------------------------------------
4) 待机表情（换一下就复原）
--------------------------------------------------
  face/wink.png      眨眼
  face/blink.png     合眼
  face/look.png      眼睛瞟别处

  待机时每 1~3 分钟看一次，30% 概率换一个表情，持续 10 秒后复原。
  只放其中一两张也能用，只有存在的会被挑中。

--------------------------------------------------
5) 尺寸建议
--------------------------------------------------
  - 全部用透明背景 PNG
  - 各图尺寸可以不同，程序按宽度自适应（默认宽度 110dp，可在设置里调 0.8~1.8 倍）
  - 建议高宽比接近 1.4 : 1（竖长一点），这样和布局槽位最贴合

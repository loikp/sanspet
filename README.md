它会一直悬浮在桌面上 —— 会自己溜达、会打瞌睡、会眨眼。你戳它一下，它用 Undertale 那种黑底白框跟你说话，一个字一个字地蹦出来，带着原作的像素音效。

接上任意 **OpenAI 兼容**的大模型接口之后，它就不只是念预设台词：能记住你们聊过什么、能感觉到你手机快没电了、能偷瞄一眼你的屏幕然后损你两句。

> 目前是 **Windows 上写完、Android 上跑通**的个人项目。代码全部开源，欢迎拿去改成你想要的样子。

## 功能

### 🐾 桌宠本体

| | |
|---|---|
| 悬浮桌面 | 常驻在所有应用上层，切到哪个界面它都在 |
| 拖动 / 锁定 | 摆哪儿记哪儿，重启还在；锁定后不能拖也不会乱走 |
| 缩放 | 0.8 ~ 1.8 倍 |
| 随机走动 | 45° 斜着溜达，边撞边折返；**间隔 3~10 分钟掷一次骰子，概率 0.6**，还看概率连着走 2~3 段（每段概率减半） |
| 待机表情 | 眨眼 / 合眼 / 眼睛瞟别处，平均 3~4 分钟来一次，每次停 10 秒 |
| 睡觉 | 10 分钟没人理它，之后每 5 分钟有 30% 概率睡着；睡着会说梦话；戳一下才醒（拖动不醒） |
| 像素音效 | 打字时每个字一声，取自原作 `snd_txtsans` |

### 💬 对话

| | |
|---|---|
| 打字机效果 | 逐字蹦出，点击可以立刻显示完 |
| 自动分段 | 长句按句号/问号/感叹号自动断句，一句不超过 30 个中文字符（英文按词断，不会把单词劈开） |
| 接着说 | 说完一句点一下看下一句；7 秒不理它会自己往下播 |
| 对话历史 | 黑框列表，每次 20 条，往上滑自动加载更早的，一键回到顶端 |
| 窗口可拖 | 对话框本身也能拖着走 |

### 🧠 记忆

| | |
|---|---|
| 上下文条数 | 默认带最近 **50 条**对话发给模型，超出自动忘掉最旧的 |
| 记忆 / 历史分离 | 「清除记忆」让它忘了聊过什么，但聊天记录还在；「清空对话历史」删记录，但它还记得 |
| 人设 | 内置人设 + 你写的追加提示词 + 你的名字 + 用户人设，四层叠起来 |

### 🎭 性格

它有自己的情绪，不是随机的 —— 是你戳出来的：

| 情绪 | 什么时候 |
|---|---|
| 烦 | 一小时里被戳 **超过 20 次** |
| 困 | 23:00 ~ 06:00 还醒着 |
| 心情不错 | 一小时里被戳 ≤ 2 次 |

有情绪的时候，说话的语气会变（会抽情绪专用台词，接 AI 时也会把情绪写进提示词）。

戳一戳还会**按一小时内被戳的次数分 5 档**反应：刚开始是亲切的打招呼，戳到 20 次以上它就彻底躺平了。

### 👀 环境感知（不用你设置，自己就开着）

Sans 偶尔会"感觉"到一点手机当下的状况，但**绝不会变成播报机器人**：

| 它能感觉到 | 什么条件下才给 |
|---|---|
| 电量低 | ≤ 15% 而且没插充电器 |
| 刚插上充电 | 插上的那一刻 |
| 断网 | 没网络连接 |
| 刚戴上耳机 / 刚静音 | 状态变化的那一刻 |
| 刚放起声音 | 有音乐或视频开始播 |
| 刚才在用的 App | 最近 30 分钟里看到的（**需要开无障碍**） |
| 连续用手机 | 一直亮屏没放下超过 2 小时 |
| 深夜 | 23:00 ~ 06:00 |

**三道闸拦着它别唠叨**：阈值（不满足条件根本不发）→ 单条冷却（同一类 3 小时内只说一次）→ 全局间隔（不管哪一类，两次之间至少隔 30 分钟）。而且提示词里写死了「跟话题没关系就完全不要提，也不要报数字」。

### 🤖 AI 相关

| | |
|---|---|
| 双模式 | **纯预设**（关键词匹配，完全离线、不花钱）/ **AI 对话**（发给云端模型） |
| 接口 | 任意 OpenAI 兼容格式：Base URL + API Key + 模型名；设置页有一键「获取模型列表」 |
| 互动走 AI | 戳一戳 / 睡着 / 醒来 / 主动开口，按一个可调概率决定走 AI 还是用预设 |
| 主动开口 | 它会自己想说话；**23:00 ~ 06:00 概率降到 1/4** —— 不关掉，照顾熬夜的人 |
| 随机读屏 | 隔一段随机时间截一张屏，让它用 Sans 的口气评论一句（默认间隔 60~180 分钟，概率 0.4） |
| 读使用数据 | 随机看你在用哪些 App，调侃一句（默认间隔 30~90 分钟，概率 0.4） |
| 报错不跳戏 | 接口超时 / 返回为空 / Key 写错，不会甩一串英文报错，而是用 Sans 的口气说，比如「……你那边是不是卡了？我等到快睡着了。（等太久没回音）」 |

## 怎么用

### 1. 安装

去 [Releases](https://github.com/loikp/sanspet/releases/latest) 下载 APK。

- 需要 **Android 8.0 以上**
- 首次安装要允许「安装未知来源应用」
- **装新版本覆盖安装就行，不用卸载**（签名是固定的）

### 2. 开权限

打开 App，按提示依次授权：

| 权限 | 干什么用 | 能不能不给我 |
|---|---|---|
| 悬浮窗 | 让桌宠显示在桌面上 | **必须**，不给你看不到它 |
| 无障碍服务 | 静默截屏（读屏功能用） | 可选。不给我就用不了"随机读屏" |
| 使用情况访问 | 读到你最近在用哪些 App | 可选。不给我就用不了"读使用数据" |

> 无障碍那个在系统设置里搜「无障碍」→ 已安装的服务 → SansPet，打开。**开一次永久有效**，重启也不用再开。

### 3. 配接口（想用 AI 才需要）

在设置页填三样：

```
Base URL   https://api.deepseek.com/v1        ← 支持 OpenAI 兼容格式
API Key    sk-xxxxxxxx                        ← 只存在你手机本地
模型        deepseek-flash
```

不知道填什么就去用 [DeepSeek](https://platform.deepseek.com/) 或者任何 OpenAI 兼容的服务，**Key 要自己申请，费用自己付**。

**不想花钱 / 懒得配**：什么都不填，它照样能玩 —— 会自动切到「纯预设」模式，说的话全部来自 `presets.json`，完全离线。

### 4. 怎么玩

- **戳它** —— 它会回应你（一直戳会烦）
- **点「聊天」按钮** —— 打开输入框，打字跟它说话
- **点「历史」按钮** —— 翻你们的聊天记录
- **按住拖动** —— 换位置（跟点击不冲突，拖了就不算点）

## 注意事项

### ⚠️ 版权（重要）

这是**非官方粉丝作品**，跟 Toby Fox 没有任何关系。

- **角色图、字体、音效**来自 Undertale 等第三方，版权不属于这个项目
- **不要拿去商用、不要上架应用商店**
- 如果你要公开发布，建议自己画一套角色图替换掉 `app/src/main/assets/character/`
- 代码本身随便看、随便改

### 💰 花钱

AI 对话会把你的话发到你自己配置的接口上，**费用是你自己的账号在付**。想省钱：

- 用便宜/免费的模型
- 把「上下文条数」调小
- 关掉读屏和使用数据
- 或者干脆用纯预设模式（不联网、不花钱）

### 🔒 隐私

- **API Key 只存在你手机本地**，不会上传到任何地方
- 聊天记录和记忆也只存本机，卸载就没了
- 但请注意：**读屏会把你的屏幕截图发送给你配置的那个模型服务商**。开之前先想清楚，涉及敏感信息的界面请关掉这个功能

### 🔧 已知限制

- 只在开发者自己的一台手机上长期测过，**其他机型没验证**
- 读屏用的是无障碍截图，**各家 ROM 的无障碍设置入口和警告文案不一样**
- 模型必须**支持图片**才能用读屏（比如 DeepSeek 的多模态、gpt-4o-mini、qwen-vl-max）。纯文本模型会直接报错
- 定时任务靠悬浮窗服务活着，**把 App 后台杀掉桌宠就没了**

## 想折腾的话

### 改它说的话（不用写代码）

编辑 `app/src/main/assets/presets.json`：

```jsonc
{
  "triggers": {
    "poke": {
      "byCount": [
        { "max": 2, "hint": "...", "lines": ["嘿，你来了。", "……嗯，我在呢。"] }
      ]
    }
  },
  "moods": {
    "annoyed": { "lines": ["……别闹。", "我现在不想说话。"] }
  }
}
```

文件开头有完整的 `_readme` 说明。改完**要重新打包**才生效（这份 json 是打进 APK 的）。

### 改它的人设

编辑 `prompt/内置人设.txt`，然后双击 `tools/同步人设.bat`。

### 改外观

角色图全部放在 `app/src/main/assets/character/`，文件名固定，放进去就生效：

```
character/idle.png          待机主图
character/sleep_0.png ...   睡觉（多帧）
character/face/wink_0.png   表情（多帧）
character/walk/left_0.png   走路（多帧）
```

多帧就是 `名字_0.png`、`名字_1.png`… 从 0 连续编号，缺一张就停。**透明背景 PNG**，不用自己切透明边。

## 开发者：自己编译

不需要本地装 Android SDK，用 GitHub Actions 云端打包。

```bash
git tag v1.0.1      # 打 tag 会自动构建 + 发 Release
git push origin v1.0.1
```

- 构建产物会自动命名成 `SansPet_v<版本号>.apk`（版本号从 `app/build.gradle.kts` 读）
- 想手动触发：仓库 Actions 页面 → Build APK → Run workflow
- 改代码前先看 `改什么看这里.md`，那是一份"想改什么去哪个文件"的索引

### 签名

正式签名已经配好了（`CN=SansPet`）。密钥没进仓库，是放在 GitHub Secrets 里的。

想在本地打包的话，把 `sanspet-release.jks` 和 `keystore.properties` 放到项目根目录即可（都已在 `.gitignore` 里）。

## 技术栈

- **外壳**：Kotlin + WebView，UI 全用 HTML/CSS/JS 写
- **悬浮窗**：Android `SYSTEM_ALERT_WINDOW`，固定尺寸（动态改尺寸会让手机卡死，踩过坑）
- **状态机**：跑在原生 Kotlin，待机 / 走动 / 睡觉三态
- **AI 请求**：走原生 `HttpURLConnection`，避开 WebView 跨域
- **存储**：`SharedPreferences`，「对话历史」和「上下文记忆」故意分开存
